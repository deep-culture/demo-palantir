### Bug fixes during user testing
1. **Foundry lineage search** lost focus after each keystroke. Fix: capture/restore `document.activeElement` (by id) around `root.innerHTML = ...` in `render()`.
2. **Gotham map markers** appeared but were unclickable. Root cause: a CSS rule `.map-canvas svg { width: 100%; min-height: 520px }` was hijacking Leaflet's internal overlay SVG, breaking marker hit positions. Fix: change to direct-child selector `.map-canvas > svg`. Also deferred `render()` from the marker click handler via `setTimeout(0)` so Leaflet's popup logic completes before the map gets destroyed.
3. **Gotham graph search** had the same focus-loss bug. Fix: applied the same capture/restore pattern, generalized to handle inputs identified by either `id` or `data-scope`+`data-field`. Audited all three per-keystroke inputs in Gotham (copilot textarea, map search, graph search) and the one in Foundry (lineage search) — all confirmed covered.
